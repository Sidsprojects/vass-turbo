# VESS TANKO — Single Page Website

A static, responsive, modern one-page company website for VESS TANKO.

## Run locally

Open `index.html` directly, or use any static server:

```bash
npx serve .
```

## Deploy to Vercel

1. Upload this folder to a GitHub repository.
2. Import the repository into Vercel.
3. Framework preset: **Other**.
4. Build command: leave empty.
5. Output directory: `.`

The website is completely static and requires no backend.

## Included

- Responsive single-page layout
- Smooth scrolling
- Scroll reveal animations
- Animated service marquee
- Responsive navigation
- Project/gallery section using supplied photos
- Global client list
- Saudi industrial collaboration section
- Google Maps embed
- Email / phone / WhatsApp CTAs
- SEO metadata
- Vercel-ready static deployment
